# Android TV for PS4 16 v0.1

Experimental Android 16 running on a jailbroken PS4, installed as a PKG. This branch contains the v0.1 port source, full kernel source and build instructions, with power/restart cleanup compiled into the normal build. The original package was released on 28 October 2026.

- [Start here: source map, build instructions and known issues](releases/android16/README.md)
- [v0.1 source release and full Linux kernel source](https://github.com/odiecay/android-tv-ps4/releases/tag/v0.1)
- [Download the original v0.1 PKG](https://www.mediafire.com/file/iau0yaa395r71lo/Android-TV-for-PS4-16-v0.1.pkg/file)
- [Android 13 / 1.1](https://github.com/odiecay/android-tv-ps4/tree/main)

Baikal support is experimental and still has black-screen reports. HDMI reconnect and restart have known problems. Read the [actual hardware status](releases/android16/STATUS.md) before testing.

You can help with code, documentation, or one clear hardware experiment. [Contributing](CONTRIBUTING.md).
